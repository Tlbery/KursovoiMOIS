# Scene11 / KursovoiMOIS

Симуляция испытательного полигона.

## Содержимое репозитория

- `Scene11.xml` – основной файл сцены
- `CustomResorces/` – текстуры, модели,

## Требования

- [MurIDE](https://murproject.com) версии 0.1.1 или выше

## Установка в MurIDE

### Способ 1: Скачивание из репозитория (рекомендуется)

```bash
1. Скачать MurIDE https://murproject.com версии 0.1.1
2. Установить MurIDE
3. Скачать файлы из репозитория
4. Добавить файлы по адресу: ..\Mur IDE\resources\simulator
5. Запустить murSimulator.exe по адресу: ..\Mur IDE\resources\simulator
6. Слева сверху нажать вкладку Open и выбрать Scene11 по адресу ..\Mur IDE\resources\simulator
